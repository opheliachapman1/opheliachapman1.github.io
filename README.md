# Ophelia Chapman – Engineering Portfolio

A static site (HTML, CSS, vanilla JS). No build step.

## Publish on GitHub Pages

1. Create a repository (e.g. `ophelia-portfolio`, or `<username>.github.io` for a root URL).
2. Upload everything in this folder: `index.html`, `styles.css`, `script.js`, and the `images/` folder.
3. In the repo, go to **Settings → Pages**, set **Source** to *Deploy from a branch*, choose `main` and `/ (root)`, and save.
4. Your site will be live at `https://<username>.github.io/<repo-name>/` within a minute or two.

## Preview locally

```
python3 -m http.server 8000
```

Then open http://localhost:8000.
